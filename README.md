# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- **山谷断网离线巡检批次**：断网时登记复测值与现场证据（照片/视频/录音/文档），网络恢复后先恢复上传证据、再与中心对账合并。
- **对账冲突保护**：同一测点同一次读数两端分别修改时，中心正式读数不被迟到离线副本覆盖，双方值只作“待核对”保留。
- **阈值版本联动**：阈值发布新版本后，相关异常在批次对账时失效重算，已关闭的异常也会重新打开。
- **可恢复提交**：证据上传失败自动退避重试、刷新页面后续传；对账与审计全部带幂等键，重放不多出审计记录。
- 总览、异常详情、审计页和JSON导出包显示同一批次、阈值版本与对账状态（同源 `batchConsistencyView`）。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
npm run test:offline   # 离线对账引擎与可恢复提交的确定性测试（24项断言）
```
